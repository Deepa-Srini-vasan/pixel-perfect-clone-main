# PLUMtek — Premium Plumbing Solutions

This project is a premium catalogue for PLUMtek, featuring a wide range of plumbing products including pipes, fittings, faucets, and accessories.

## Technologies Used

- **React** with **TypeScript**
- **Vite** for fast development
- **Tailwind CSS** for styling
- **Lucide React** for iconography
- **Shadcn UI** components

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```sh
# Clone the repository
git clone <git-url>

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Features

- **Premium UI**: Sleek, minimalist design tailored for a high-end brand experience.
- **Product Filtering**: Advanced category-based filtering for the extensive product line.
- **Key Milestones**: Interactive historical timeline of the company's growth.
- **Responsive Design**: Optimized for all device sizes.
